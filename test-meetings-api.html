Endpoint: GET /api/meetings/:id

Description: Fetch a single meeting with transcript and AI analysis

Endpoint: PUT /api/meetings/:id

Description: Update an existing meeting

DELETE Delete Meeting

Description: Delete a meeting

🎙️ Section 4: Recording & Advanced Features

POST Start Recording

Endpoint: POST /api/meetings/:id/start

Description: Start recording a meeting

ℹ️ This initiates recording mode. Status will be updated to indicate active recording.

POST End Recording

Endpoint: POST /api/meetings/:id/end

Description: End recording and upload audio for transcription

ℹ️ Note: This test uses a sample base64 audio string. In production, this would be actual recorded audio data.

PUT Update Speaker Map

Endpoint: PUT /api/meetings/:id/speaker-map

Description: Map speaker IDs to names in transcript

ℹ️ Maps anonymous speaker IDs to actual participant names for better readability.

POST Regenerate Content

Endpoint: POST /api/meetings/:id/regenerate

Description: Regenerate summary, transcription, or both

ℹ️ Useful for improving AI-generated content quality or after updating speaker names.

POST Send Notifications

Endpoint: POST /api/meetings/:id/notify

Description: Send meeting notifications to all participants

ℹ️ Sends notifications via email/SMS to all meeting participants about the meeting details.
